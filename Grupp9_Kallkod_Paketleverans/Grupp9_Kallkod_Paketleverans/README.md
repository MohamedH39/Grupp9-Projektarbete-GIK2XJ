# Paketleverans och spårning – Grupp 9

Konsolapplikation i C#/.NET 8 för att registrera, spåra och uppdatera paket. Projektet visar Strategy och Observer samt en enkel objektorienterad struktur.


## Centrala funktioner

- Registrera paket med adresser, terminaler och standard, express eller skört gods.
- Beräkna pris och prioritet med Strategy.
- Lagra paket i en Dictionary och söka med spårningsnummer.
- Hålla ordning på stationer med en Queue.
- Kontrollera tillåtna statusövergångar.
- Meddela kunden vid statusändringar med Observer.
- Sortera paket efter prioritet med insertion sort.
- Köra två demonstrationer och fyra inbyggda självtester.
